POCKET BAND

Firmware for the M-VAVE FM-1

A band in your FM-1. Pick a place on a map of sixteen genre towns and it writes a four-piece sketch in one key and tempo; then re-roll, audition, jam, perform and edit it.

Before you install

Pocket Band is experimental and comes with no warranty. Install it at your own risk.

  1. Back up first. If the FM-1 holds anything you want to keep, save it with the tool of the firmware it runs now. Pocket Band does not open other firmwares' projects, and it writes its own over them.
  2. Connect. A USB-C data cable straight to the computer, no hub. Close any other app or tab that uses MIDI.
  3. Use Chrome or Edge on a computer, and allow MIDI access when the browser asks.
  4. Press INSTALL and leave the FM-1 alone until the page says it is done. Do not unplug it.
  5. Try it. Press GLO for the map, walk with KNOB 1 and KNOB 2, press GLO again to travel.

If the FM-1 does not start afterwards: switch it off, hold OCT− alone and switch it on (USB rescue), then press INSTALL again.
