# Changes

- REC a second time: tap. Tap a rhythm on any key and the notes are picked from each bar's chord.
- Jam: TOUR walks the band on along the map every 16 or 32 bars.
- A hidden place off the south-east corner of the map, and four code words.
- The keys now snap to the sketch's scale.
- Its own package identity (`FM-1_7226` + version) and name on every screen, the rescue screen included.
- The repository holds Pocket Band only: SLOOP's site, web editor, documents and artwork are gone;
  credits and licences are in `CREDITS.md` and `LICENSING.md`.

Tested on a computer only.
